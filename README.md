🤖 AI Resume Screener

An AI-powered Resume Screening system that analyzes resumes and matches them with job descriptions to provide intelligent insights, scoring, and improvement suggestions.

⸻

📌 Overview

The AI Resume Screener helps recruiters and job seekers by automating the resume evaluation process using AI.
	•	Upload a resume (PDF/DOC)
	•	Provide a job description
	•	Get a match score, skills analysis, and AI suggestions

⸻

🚀 Features
	•	📄 Resume Upload & Parsing (PDF/DOC)
	•	🧠 AI-Based Resume Analysis
	•	📊 Job Description Matching
	•	✅ Match Score Calculation
	•	🔍 Skill Gap Identification
	•	✨ AI Suggestions for Improvement
	•	📁 Clean REST API (Spring Boot)

⸻

🏗️ Tech Stack

Backend
	•	Java + Spring Boot
	•	Spring Web
	•	Spring Security (JWT - optional)
	•	MongoDB / MySQL

AI Integration
	•	OpenAI API / LLM
	•	NLP-based keyword extraction

Other Tools
	•	Maven / Gradle
	•	Postman (API Testing)

⸻

⚙️ How It Works
	1.	User uploads a resume
	2.	System extracts text from the resume
	3.	User inputs a job description
	4.	AI compares resume vs job description
	5.	System returns:
	•	Match Score (%)
	•	Missing Skills
	•	Improvement Suggestions
